# 🍔 Foodie Restaurant Website

A modern and responsive restaurant landing page built using HTML, CSS, Bootstrap, and JavaScript.

## ✨ Features

- Responsive Design
- Modern Navigation Bar
- Hero Section
- About Section
- Popular Dishes Menu
- Food Gallery
- Customer Testimonials
- Contact Form
- Beautiful Footer
- Smooth Hover Effects

## 🛠️ Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
